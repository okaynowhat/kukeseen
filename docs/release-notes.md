Kukeseen for Android: chanterelle spot finder for the Tartu region.

- Evidence-tiered chanterelle spots with sources, distance list and route text from Haaslava
- Forest-register habitat layer: pine and spruce stands 40+ with site type, age and height
- GPS compass to a spot, drive hand-off to Google Maps, Apple Maps, Waze
- Offline map tiles and stands per spot
- Private find log with photo, GPS and GPX export (stays on the phone)
- Lessons and quiz in Estonian and English, season index from Open-Meteo

Install: open the APK, allow installing from this source once. Web version: https://okaynowhat.github.io/kukeseen/
